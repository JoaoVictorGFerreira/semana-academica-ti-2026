# Semana Acadêmica de TI 2026

Landing page desenvolvida para divulgar a Semana Acadêmica dos Cursos de Tecnologia da Informação, como projeto semestral de Programação Front-end.

## Objetivo

Apresentar informações sobre o evento, programação, palestrantes e atividades, além de uma seção de perguntas frequentes.

## Tecnologias utilizadas

- HTML: estrutura e conteúdo da página.
- CSS: estilização e adaptação para diferentes tamanhos de tela.
- JavaScript: interação das perguntas frequentes e aviso de inscrições.

## Como executar

Baixe ou clone este repositório e abra o arquivo index.html no navegador.

## Status do projeto

Em desenvolvimento. O botão de inscrição exibe um aviso; ainda não realiza inscrições.
